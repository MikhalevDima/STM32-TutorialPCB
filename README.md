# [MSPM0-TutorialPCB]
Двухслойная печатная плата (PCB), спроектированная в **KiCad** с использованием методологии и лучших практик инженерного канала **Phil's Lab**.

## 🛠 Ключевые характеристики и компоненты
- **Микроконтроллер/Базовый чип:** STM32WB55CEU6.
- **Количество слоев:** 4 слоя.
- **Толщина платы / Финиш:** Разработано под стандартные 1.58 мм.
- **Интерфейсы и питание:** USB Type-C для питания и данных.
## 🚀 Что было реализовано в проекте (Инженерные навыки)
В процессе разработки этого устройства были применены следующие практики:
1. **Схемотехника и подбор компонентов:** Полный цикл отрисовки схемы, расчет номиналов обвязки (конденсаторы фильтрации, подтягивающие резисторы) на основе технической документации (Data Sheets).
2. **Интерактивная трассировка (KiCad):** Использование современных режимов трассировщика (*Shove*, *Walk Around*) для обеспечения плотного и аккуратного монтажа. С контролем импеданса 50 Ом.
3. **Цепи питания и заземления:** Организованы сплошные полигоны заземления (`GND`) для снижения помех, настроены корректные тепловые барьеры (*Thermal Reliefs*) для падов.
4. **Управление правилами проектирования (DRC):** Настроены классы цепей (*Net Classes*) и технологические зазоры (*Clearance*, *Margin*, *Courtyard*).
  ## 📁 Структура репозитория
- `/hardware` — исходные файлы проекта KiCad (`.kicad_sch`, `.kicad_pcb`).
- `/production` — итоговый пакет для завода:
  - `gerbers/` — файлы слоев в формате Gerber и файлы сверловки (`.drl`).
  - `bom/` — ведомость материалов (BOM) в формате CSV для закупки.
  - `position/` — файлы координат (`.pos`) для робота-установщика SMD.
- `/docs` — принципиальная схема в формате [PDF](docs/schematic.pdf) для быстрого просмотра (без необходимости открывать САПР).
